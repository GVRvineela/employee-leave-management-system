# Employee Leave Management System

## Project Description
A simple Python-based Employee Leave Management
System that allows employees to apply for leave
and administrators to view employee details and
leave applications.

## Features
- Add employees
- View employee details
- Apply for leave
- View leave applications
- Store data using JSON files

## Technologies Used
- Python
- JSON
- Git
- GitHub

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

python main.py

## Leave Approval Rules

The system follows these approval rules:

- Leave requests up to 5 days are automatically approved.
- Leave requests exceeding 5 days require manager approval.
- Invalid employee IDs are rejected.
- Leave days must be greater than zero.

## Data Storage

Employee and leave information is stored
in JSON files inside the data folder.

This project uses Git for version control
